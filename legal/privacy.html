2Data Collected

  • IMAP/SMTP access credentials: email address and OAuth2 token (no password is ever stored when using Google or Microsoft sign-in).
  • Mailbox content: message headers, subjects, bodies and attachments — read directly from the user's IMAP server and never copied to Frickmail's storage.
  • Google Contacts: name and email address of contacts, synced via the Google People API and stored in the local address book.
  • Google Calendar: events and appointments, read and written via the Google Calendar API.
  • Session data: technical session cookies required for the web interface to function.
  • Server logs: IP address, date/time and request URL, retained for security purposes.

3Use of Google API Data

Limited Use Disclosure: Frickmail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Frickmail requests the following Google scopes:

  • openid, email, profile — Google account identification.
  • https://mail.google.com/ — IMAP and SMTP access to the Gmail mailbox.
  • https://www.googleapis.com/auth/contacts.readonly — reading Google Contacts for the local address book.
  • https://www.googleapis.com/auth/calendar — reading and writing Google Calendar events.

Data obtained through Google APIs is never used for advertising, profiling, or transferred to third parties for AI training or any other purpose.

4Purpose and Legal Basis

Data is processed exclusively to provide the webmail service, synchronise contacts and calendar, and ensure security. The legal basis is the controller's legitimate interest and the user's explicit consent given via OAuth2 authorisation.

5Data Retention

  • OAuth2 tokens: stored encrypted for the duration of the active session. Revoking access via the Google or Microsoft account console immediately invalidates them.
  • Synced contacts: retained until the user requests deletion or removes the account.
  • Server logs: retained for a maximum of 30 days, then automatically deleted.
  • Email messages: not stored on Frickmail; they reside exclusively on the user's IMAP server.

6Third-Party Sharing

Frickmail does not sell, rent or share personal data with third parties for commercial purposes. Data is transmitted to Google and Microsoft solely to authenticate the user and access the services they provide, in accordance with their respective policies:

9Security

All communications use encrypted HTTPS connections (TLS 1.2/1.3). OAuth2 tokens are encrypted at rest. Server access is restricted to authorised users; there is no public access to the database or logs.

1Personuppgiftsansvarig

Personuppgiftsansvarig är Nicola Francesconi, nåbar på nicola.francesconi@gmail.com.

Frickmail är ett självhostat webbmailprogram tillgängligt på https://webmail.housefz.com. Det är en privat tjänst reserverad för auktoriserade användare.

2Insamlade uppgifter

  • IMAP/SMTP-inloggningsuppgifter: e-postadress och OAuth2-token (inget lösenord lagras vid inloggning med Google eller Microsoft).
  • Brevlådeinnehåll: rubriker, ämnen, meddelandetext och bilagor — läses direkt från användarens IMAP-server och kopieras aldrig till Frickmail.
  • Google Kontakter: namn och e-postadress, synkroniserade via Google People API och lagrade i den lokala adressboken.
  • Google Kalender: händelser och möten, lästa och skrivna via Google Calendar API.
  • Sessionsdata: tekniska sessionscookies som krävs för webbgränssnittet.
  • Serverloggar: IP-adress, datum/tid och begärda URL:er, sparade i säkerhetssyfte.

3Användning av Google API-data

Deklaration om begränsad användning: Frickmails användning av information från Google API:er följer Google API Services policy för användardata, inklusive kraven på begränsad användning.

Frickmail begär följande Google-behörigheter (scopes):

  • openid, email, profile — identifiering av Google-kontot.
  • https://mail.google.com/ — IMAP- och SMTP-åtkomst till Gmail-brevlådan.
  • https://www.googleapis.com/auth/contacts.readonly — läsning av Google Kontakter för den lokala adressboken.
  • https://www.googleapis.com/auth/calendar — läsning och skrivning av Google Kalender-händelser.

Data från Google API:er används aldrig för reklam, profilering eller överföring till tredje part för AI-träning.

4Ändamål och rättslig grund

Data behandlas uteslutande för att tillhandahålla webmailtjänsten, synkronisera kontakter och kalender samt säkerställa säkerheten. Den rättsliga grunden är den personuppgiftsansvariges berättigade intresse och användarens uttryckliga samtycke via OAuth2.

5Datalagring

  • OAuth2-token: lagras krypterade under den aktiva sessionens varaktighet. Återkallelse via Google eller Microsoft ogiltigförklarar dem omedelbart.
  • Synkroniserade kontakter: behålls tills användaren begär radering.
  • Serverloggar: maximalt 30 dagar, raderas sedan automatiskt.
  • E-postmeddelanden: lagras inte på Frickmail; de finns enbart på användarens IMAP-server.

6Delning med tredje parter

Frickmail säljer, hyr ut eller delar inte personuppgifter med tredje parter i kommersiellt syfte. Data överförs till Google och Microsoft enbart för autentisering:

  • Googles sekretesspolicy
  • Microsofts sekretesspolicy

Kontakta nicola.francesconi@gmail.com för att utöva dessa rättigheter.

8Cookies

Frickmail använder enbart tekniska sessionscookies som krävs för att applikationen ska fungera. Inga spårnings-, analys- eller reklamcookies från tredje part används.

9Säkerhet

All kommunikation sker via krypterade HTTPS-anslutningar (TLS 1.2/1.3). OAuth2-token lagras krypterade. Serveråtkomsten är begränsad till auktoriserade användare.
